# PiOps

PiOps is a personal automation and monitoring platform running on a
Raspberry Pi 3 B+.

The project is designed as a hands-on environment for learning Linux,
Python automation, networking, APIs, monitoring, reliability, and
DevOps concepts.

## Hardware

- Raspberry Pi 3 B+
- No additional hardware required

## Planned Features

- System health monitoring
- Scheduled automation
- Website/API uptime monitoring
- Logging and historical metrics
- Automated notifications
- REST API
- Dashboard
- GitHub integration
- Automated testing/deployment
- Backup automation
